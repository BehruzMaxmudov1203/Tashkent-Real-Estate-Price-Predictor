# Tashkent Real Estate Dataset

This directory contains the dataset used for training and evaluating house price prediction models.

## Dataset Information
- **Filename:** `housing_data_08-02-2021.csv`
- **Total Records:** 7,565 rows
- **Columns:**
  - `location`: Specific address/subdistrict of the apartment in Tashkent.
  - `district`: Administrative district in Tashkent (e.g., Chilanzar, Yunusabad, Mirzo-Ulugbek, etc.).
  - `rooms`: Number of rooms in the apartment.
  - `size`: Living area in square meters ($m^2$).
  - `level`: Floor level on which the apartment is situated.
  - `max_levels`: Total number of floors in the residential building.
  - `price`: Listing price in USD ($).

## Source
- Dataset collected from Tashkent real estate listings by Anvar Narzullaev (Mohirdev / Praktikum).
- Direct URL: `https://raw.githubusercontent.com/anvarnarz/praktikum_datasets/main/housing_data_08-02-2021.csv`
